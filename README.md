## English

Six unofficial desktop pets inspired by the NewJeans × The Powerpuff Girls designs: Minji, Hanni, Danielle, Haerin, Hyein, and Bunnies. Each has nine animations: idle, run right, run left, wave, jump, failure, waiting, thinking, and review. The v2 assets also include sixteen look directions. Minji sets the timing reference; each character keeps their own palette and accessories.

The free download pack is being prepared for [Releases](../../releases). Unzip it and import the chosen character’s transparent PNG or WebP in the Pets panel of ChatGPT Work. GIFs are for preview.
